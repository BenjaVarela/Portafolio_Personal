## Tecnologías Utilizadas
* **HTML5:** Estructura 100% semántica y accesible (reemplazo de divs por landmarks `main`, `header`, `nav`, `section`, `footer`).
* **CSS3:** Diseño responsivo puro con CSS Grid, Flexbox y variables de color.
* **WAI-ARIA & Accesibilidad:** Uso de atributos `aria-labelledby`, `aria-label`, `<label>` explícitos y estados `:focus-visible`.
* **Git & GitHub:** Control de versiones y alojamiento de repositorio.
* **Render:** Despliegue en la nube como sitio estático.

## Decisiones de Diseño y Accesibilidad
* **Audiencia Objetivo:** Reclutadores IT y docentes académicos.
* **Jerarquía Visual y Paleta:** Se utilizó una paleta azulada con alto contraste que facilita la lectura y destaca los botones que redirigen a mis repositorios de proyectos en GitHub.
* **Responsividad (3 Breakpoints):**
  * **Escritorio (>1024px):** Layout completo a 3 columnas en la sección de proyectos.
  * **Tablet (768px - 1024px):** Grilla adaptada a 2 columnas.
  * **Móvil (<768px):** Columna única para una lectura limpia en teléfonos.
